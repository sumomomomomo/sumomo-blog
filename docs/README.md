# Reference Documents

This directory contains third-party reference material used during the development of the A2A protocol demos. These documents are **not** part of the site build and are included for development and documentation purposes only.

## a2a-specs.md

- **Source:** [Agent2Agent (A2A) Protocol Specification](https://a2a-protocol.org/latest/specification/) — © the A2A project authors.
- **What it is:** A local snapshot of the A2A specification markdown, used as the reference for the interactive demos in `app/src/pages/a2a/` (section numbers, object descriptions, and error semantics surfaced in the spec popovers).
- **Accessed:** 11 September 2026.
- **Status:** Static snapshot — it will not track updates to the live specification. Always consult [a2a-protocol.org](https://a2a-protocol.org/latest/specification/) for the current, authoritative version.
- **Note:** The file retains the spec repository's build-template placeholders (e.g. `{{ proto_to_table("Task") }}`); object tables were rendered on the live site at access time.
